# Skill packs

Markdown skill briefings served by `codix.architecture.get` and `codix.context.smart`. Each subfolder is a focused body of knowledge an agent can ground itself in without bloating the context window.

| Folder | Topic |
|---|---|
| `architecture/` | Monolith vs microservices, Laravel modules, Next.js App Router, Flutter clean arch |
| `security/` | OWASP top 10, secret handling, OAuth 2.0 / OIDC, JWT pitfalls |
| `docs/` | README templates, CONTRIBUTING, CHANGELOG conventions |
| `business-kit/` | Pricing, terms, refund policy, marketplace pitch |

Each pack ships an `index.md` entry point with short, single-purpose guidance.
