# FAQ

## Does this MCP create projects directly?

No. It gives AI agents accurate context, templates, checklists and instructions. The coding agent applies them in the target repo.

## Does it need a Codinfy secret?

No. `CODIX_BUILD_API_KEY` is optional for future quotas only. v0.1.0 runs fully in public local mode.

## Does it include Login with Codinfy and Ads?

It includes integration guidance and readiness checks. It does not fabricate platform endpoints that have not shipped in a target app.

## Why Smart Context Mode?

It reduces long pasted prompts by selecting only the relevant context chunks for the current task.
