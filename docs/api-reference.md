# Codix Build MCP - Tool Reference

All tools are local, deterministic and public-safe.

## Analyze and plan

- `codix.project.analyze` - brief to project type, modules, risks and milestones.
- `codix.stack.recommend` - stack choice by project type, budget, team level and hosting.
- `codix.architecture.get` - layers and build order for stack and project type.
- `codix.context.smart` - minimal context chunks for the current task.

## Generate

- `codix.prompt.generate` - compact implementation/review/handoff prompt.
- `codix.template.get` - starter file tree, commands and template notes.
- `codix.license.inject` - license integration checklist.
- `codix.design.apply` - design tokens and UX component set.
- `codix.api.generate` - API routes, validation and tests.
- `codix.database.schema` - migrations, relations and seeders.

## Quality and ops

- `codix.security.checklist` - security checklist by features.
- `codix.marketplace.check` - Codinfy Store / CodeCanyon readiness.
- `codix.docs.generate` - documentation outline.
- `codix.deploy.guide` - deploy steps by target.
- `codix.debug.help` - likely causes and commands from an error.
- `codix.cost.optimize` - token and infrastructure cost reductions.
